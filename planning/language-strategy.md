# Language Strategy

## Core Position

We are not building for English-only classrooms.

We are building an English-teaching product that uses Nigerian languages as scaffolding for comprehension.

## Why This Matters

Many learners understand new ideas faster when explanations connect to the language they already speak at home or in their community.

That means our product value is not just:

- generate English lesson materials

It is:

- help teachers bridge from familiar language to English understanding

## MVP Rule

Do not attempt to support all Nigerian languages in the first version.

That would create:

- shallow quality
- inconsistent terminology
- weak demo credibility

Instead, we should support a very small set well.

## Recommended MVP Language Model

Primary output language:

- English

Support languages:

- choose one or two first

Recommended strategy:

- one high-coverage language for broader relevance
- one locally authentic language that gives the project character

Possible combinations:

- English + Yoruba + Efik
- English + Hausa + Ibibio
- English + Yoruba only
- English + Efik only

## Best Product Framing

Version one:

- Teach English with local-language support

Version two:

- Teach Basic Science with local-language support

This sequencing is better than launching both subjects at once.

## Language Pack Concept

Each supported language should eventually have:

- common classroom phrases
- glossary of core educational terms
- subject vocabulary by level
- prompt examples
- style guidance for concise explanations

## What We Need From Each Language

Minimum viable quality means:

- clear understandable phrasing
- consistent key terms
- short explanation style
- teacher-readable output

We do not need perfect linguistic coverage of every dialect in the MVP.

## Recommended Immediate Choice

If we want strongest reach:

- English + Yoruba or Hausa

If we want strongest authenticity and distinctiveness:

- English + Efik or Ibibio

If we want both:

- launch one major language and one local differentiator

## Product Example

Teacher chooses:

- `Primary 5 English`
- support language: `Efik`
- topic: `Nouns and pronouns`

App generates:

- lesson objective in English
- simple teacher explanation in English
- support explanation in Efik
- examples
- class activity
- quiz and answer key

## Guardrail

The support language is there to improve teaching and comprehension.

It is not there to turn the app into a general-purpose translation product.
