# First Teaching Slice

## Goal

Define the exact version of the product we will build first.

## Recommended Default

- Subject: `Primary English`
- Class level: `Primary 5`
- Support language: `Efik`

## Why This Slice Works

- It is small enough to finish.
- It supports a strong bilingual teaching story.
- It is concrete enough for curriculum packaging.
- It is distinctive without being too broad.

## Alternative Slice

- Subject: `Primary English`
- Class level: `Primary 5`
- Support language: `Ibibio`

Choose Ibibio instead of Efik only if:

- you have better language confidence
- you have easier access to validation help
- you can create a stronger authentic glossary for it

## Recommended First Topic Set

Start with 8 topics max:

- Nouns
- Pronouns
- Verbs
- Adjectives
- Simple sentence structure
- Comprehension passage support
- Tenses
- Parts of speech overview

## Why These Topics

- easy to explain in short structured form
- familiar to teachers
- easy to generate quizzes for
- easy to judge in a demo

## Fixed Lesson Output Schema

Every lesson should include:

- lesson title
- class level
- learning objective
- teacher explanation in English
- support explanation in selected language
- examples
- classroom activity
- five quiz questions
- answer key
- take-home revision note

## What We Need To Prepare

- one lesson schema
- one topic list
- one local-language glossary
- one classroom phrase list
- one saved-lesson data model

## Non-Goal

We are not trying to cover the full national curriculum in version one.
