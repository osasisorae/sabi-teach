# Submission Checklist

## Required Competition Assets

- Kaggle writeup
- public video
- public code repository
- live demo
- media gallery cover image

## Product Deliverables We Need

- working mobile app build
- clear teacher workflow
- real Gemma 4 integration
- offline-capable demonstration
- sample curriculum pack
- polished demo script

## Code Repository Requirements

- clear README
- setup instructions
- architecture explanation
- screenshots or demo GIFs
- explanation of Gemma 4 usage

## Writeup Requirements

- under 1,500 words
- clear title and subtitle
- selected competition track
- architecture explanation
- challenges and tradeoffs
- why Gemma 4 was the right fit

## Video Requirements

- 3 minutes or less
- strong story in the first 20 seconds
- real product footage
- clear before and after
- no fake product behavior

## Live Demo Requirements

- accessible without login if possible
- or packaged files if hosted demo is not practical
- stable enough for judges to inspect

## Internal Milestones

- lock product scope
- choose exact subject and class level
- decide mobile stack
- implement main generation flow
- implement offline lesson history
- produce first usable demo build
- record video
- finalize writeup
- publish repo and demo assets

## Red Flags

- product still feels generic
- Gemma 4 use is unclear
- app depends on constant internet
- demo is mostly slides instead of product
- writeup sounds bigger than what the build proves
